# PTN

《无期迷途》异方晶桌面小组件，适用于 macOS。

## 安装

1. 下载仓库源码。
2. 打开终端，进入项目目录。
3. 运行：

```bash
cd /Users/admin/Developer/5732
./build-standalone-app.sh
```

4. 编译完成后，会自动打开小组件。
5. 生成的应用位置：

```bash
dist/PTNHypercubeWidget.app
```

## 使用

1. 打开小组件后，它会显示在桌面上。
2. 顶部可查看：
   - 总抽数
   - UP 数
   - 蓝票、红票、异方晶
3. 点击右上角编辑按钮，可以手动修改当前库存。
4. 当前周期中的任务可以直接勾选或取消。
5. 抽卡规划页可记录：
   - 想抽
   - 已抽完
   - UP 选择
   - 垫抽数
6. 点击底部“历史”可以查看记录并撤销最近一条。
7. 点击状态栏图标，可进行：
   - 显示/隐藏小组件
   - 切换更半透明
   - 退出

## 备注

- 数据保存在本机。
- 重新打开后会保留上次的位置和记录。
